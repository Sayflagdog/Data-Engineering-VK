## Методика

- Фильтр: role = `DevOps-инженер` ИЛИ отдельное DevOps / Dev Ops / Dev-Ops /
  девопс в name без учёта регистра. SQL и Python реализуют условие независимо.
- Навыки: `;`, trim, lower, уникальные значения в вакансии, сортировка.
  Синонимы не объединяются. Каждая комбинация учитывается один раз на вакансию.
- Размеры стека: первые 5, 10, 30 нормализованных навыков в алфавитном порядке.
  Значения выбраны как допущение: в присланном ТЗ точных размеров нет.
- MapReduce читает S3 потоком; чанк — 1000 отобранных вакансий, два mapper.
- DuckDB читает тот же объект `s3://hh-lake/raw/it_vacancies_2024.csv`, два потока.
- Зарплата: только RUR, gross=false, среднее двух границ либо одна доступная
  граница, положительные значения, без перевёрнутых диапазонов. FX и налоговые
  преобразования не выполняются. Это приближение объявленной зарплаты.
- Для пары база — более частый отдельный навык, для тройки — более частая
  содержащаяся пара; частота базы определяется по всем DevOps-вакансиям.
  При равенстве берётся лексикографически первая база.
- Порог рейтинга — минимум 20 сопоставимых зарплат у сочетания и у базы.
- Регионы: Москва, Санкт-Петербург, Екатеринбург. Таблица 1 — объём и зарплаты;
  таблица 2 — топ-10 навыков, пар и троек в каждом регионе, частоты и зарплаты.
  Точная форма двух региональных таблиц в присланном ТЗ не задана.
- 3 запуска каждого способа на каждом стеке, отдельно 3 оптимизированных запуска
  для стека 30. Новые процессы; порядок методов чередуется. Кэш ОС не очищается.
- RSS: сэмплирование каждые 20 мс, сумма RSS процесса расчёта и mapper;
  RustFS не включён, общие страницы могут учитываться несколько раз.
- Принудительное завершение mapper и повтор незакоммиченной группы без дублей.
- Полная сверка всех частот и независимая Python-проверка зарплатных медиан.

## Результаты

`results/storage.json` — GET, размер и SHA-256 исходного S3-объекта.
`data_quality.json` — численность, пропуски, регионы и размеры стеков.
`benchmark_runs.csv` — сырые попытки, `benchmark_summary.csv` — медианы.
`verification.json` — полная сверка частот, `mapper_failure.json` — сбой mapper.
`analysis_verification.json` — Python против SQL для зарплат и регионов.
`salary_all_supported.csv` — все прошедшие порог сочетания с базой и квартилями.
`salary_top.csv` — наибольшие положительные и отрицательные различия медиан.
`regions_summary.csv` и `regions_skills_pairs_triples.csv` — две региональные таблицы.
`sql/` — SQL подготовки данных, частот и зарплат.
`report/` — итоговый PDF и графики.

Рейтинги описывают связь, не причинный эффект навыка. Опыт, работодатель, регион
и раскрытие зарплаты могут объяснять различия. Набор относится к вакансиям 2024 года.
